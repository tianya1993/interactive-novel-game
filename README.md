# 互动小说游戏

AI 驱动的互动小说游戏平台，支持历史穿越和系统文剧本。

## 快速开始

```bash
git clone https://github.com/tianya1993/interactive-novel-game.git
cd interactive-novel-game
bash install.sh
```

## 游戏类型

| 类型 | 说明 |
|------|------|
| 历史穿越 | 穿越到历史时期，改变历史或生存发展 |
| 系统文 | 获得神秘系统，通过完成任务升级变强 |

## 技术栈

- 前端：HTML + CSS + JavaScript
- 后端：Python（可选）
- AI：支持 SiliconFlow、DeepSeek、OpenAI 等

## 项目结构

```
assets/      # 前端页面
docs/        # 项目文档
scripts/     # 后端脚本
skills/      # AI 技能配置
```
